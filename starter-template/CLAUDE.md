# ໂປຣເຈັກ: <ຊື່ໂປຣເຈັກ>

ຕອບເປັນພາສາລາວ.

## ກົດການເຮັດວຽກ
- ກ່ອນແກ້: ອ່ານໄຟລ໌ທີ່ກ່ຽວຂ້ອງກ່ອນ ແລະບອກແຜນສັ້ນໆ
- ແກ້ເທື່ອລະເລື່ອງ; ແກ້ແລ້ວທົດສອບໃນ browser ແລະລາຍງານຜົນຈິງ
- ກ່ອນຈົບ: ກວດຄືນວ່າເຮັດຄົບທຸກຂໍ້ທີ່ສັ່ງ ແລະບອກລາຍການທີ່ຍັງບໍ່ໄດ້ເຮັດ
- commit ເມື່ອແຕ່ລະວຽກຈົບ; push ຂຶ້ນ GitHub ສະເພາະເມື່ອຂ້ອຍບອກ
- ຫ້າມລຶບໄຟລ໌ໂດຍບໍ່ຖາມ

## ໂຄງສ້າງ
- `index.html`  ໜ້າຫຼັກ
- `models/`     ໄຟລ໌ GLB ເທົ່ານັ້ນ (ຢ່າຝັງ base64 ໃນ HTML)
- `textures/`   ຮູບ texture
- `vendor/`     ໄລບຣາຣີ (ເຊັ່ນ three.js)
- `tools/`      ສະຄຣິບ build
- `source/`     ໄຟລ໌ຕົ້ນສະບັບ (SketchUp/CAD) — ບໍ່ push
